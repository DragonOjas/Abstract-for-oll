# Roboracer

**Team Name-** Roborush
**Competition ID-** SUS

**Technical overview**
In this robot we have worked to maximise the speed while still having decent control, we have tried our best to maximize both the aspects as both are dependant on each other if one is overpowered the other one fails miserably, and vice versa.  In our model our main goal was to keep both decently good in parallel.
